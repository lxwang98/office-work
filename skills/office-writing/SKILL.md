# 中文办公文书写作规范

本技能是「职场办公模式」的写作底座。**动手写之前先读对应的文种章节**，按提纲组织内容，
再落到 Word 或 Markdown 文件。用户多为体制内财务人员、医院临床医生和一般职场人士，
他们看重的是"拿得出手、经得起问"，而不是辞藻。

## 一、四条硬性纪律（违反即返工）

1. **数字只能来自读到的数据。** 报告里的每个金额、数量、比例、同比，都必须能追溯到用户
   提供的表格或文件。缺数据就写占位符 `（此处需补充×××数据）`，并在结尾列出需要用户补什么。
2. **不编造人名、日期、文号、政策文件名、文献引用。** 用户没给的一律留占位符：`（文号）`、
   `（发文单位）`、`（参考文献）`。
3. **不擅自替用户下结论。** 涉及评价、定性（如"存在严重违规""效果显著"）时，用用户提供的
   事实说话；没有依据就改成中性表述，或把判断权交回用户。
4. **涉密与个人信息从简。** 身份证号、手机号、病历号、工资明细等，除非确有必要，不写进
   正文；必须写时也只写必要位数。

## 二、通用行文规范

### 结构层次
- 第一层：`一、` `二、` `三、`（顿号，后不接标点直接跟标题文字）
- 第二层：`（一）` `（二）` `（三）`（括号后不加顿号）
- 第三层：`1.` `2.` `3.`（数字后用小圆点）
- 第四层：`（1）` `（2）`
- 层次不宜超过四层；能用短段落说清的不要硬拆层级。

### 数字与计量
- 统计数字、金额、比例、时间用阿拉伯数字：`3 个单位`、`120.5 万元`、`同比增长 8.3%`。
- 成文日期、公文标题中的年份用阿拉伯数字：`2024年5月6日`；正文中的日期同样写
  `2024年5月6日`，不要写 `2024-5-6`。
- 金额超过四位用千分位：`1,250,000 元`；合同、报销说明中需同时给出大写：
  `人民币壹佰贰拾伍万元整`。
- 概数、约数用汉字：`三四个`、`十几个`、`五六年`。
- 计量单位用法定单位并统一：`平方米`、`千瓦时`、`例`、`人次`。

### 语言
- 务实、克制。少用形容词和程度副词（"极大""显著提升"要有数据支撑才用）。
- 一句话说一件事，长句拆短。
- 并列事项一律分点，不堆在一个长句里用顿号串起来。
- 称谓统一：本单位用「我单位」「我科」「我院」，对方用「贵单位」。
- 避免口语与网络语；避免"进行了一个……的动作"这类空转句式。

### 常用起句与结语
| 文种 | 起句 | 结语 |
|---|---|---|
| 通知 | 为……，经研究决定，现将有关事项通知如下： | 请遵照执行。 |
| 报告 | 现将有关情况报告如下： | 特此报告。 |
| 请示 | 因……，现请示如下： | 妥否，请批示。 |
| 批复 | 你单位《关于……的请示》（文号）收悉。经研究，现批复如下： | 此复。 |
| 函 | 现就……有关事宜函告如下： | 请予支持为盼。／盼复。 |
| 纪要 | 会议听取了……，与会人员进行了讨论。现将议定事项纪要如下： | — |
| 总结 | ……年，在……领导下，我单位紧紧围绕……，现将情况总结如下： | — |
| 述职 | 根据……要求，现将本人一年来的履职情况报告如下： | 以上报告，请予评议。 |

## 三、文种提纲库

### 公文类

**通知** — 标题（关于……的通知）→ 主送单位 → 缘由 → 通知事项（分条）→ 执行要求 → 落款。
要点：事项写到"谁、何时、何地、做什么、带什么材料、联系谁"。
篇幅：400–800 字。

**报告** — 标题 → 主送机关 → 缘由 → 主要做法与成效 → 存在问题 → 下一步打算 → 落款。
要点：成效分点且每点先结论后支撑；问题客观不回避；下一步要可落地。
篇幅：1000–2500 字。

**请示** — 标题 → 主送机关 → 请示缘由 → 请示事项 → 附件 → 落款。
要点：**一文一事**；事项具体到金额、数量、时间；理由要能挂上政策依据或实际困难。
篇幅：500–1200 字。

**批复** — 标题 → 主送机关 → 引述来文 → 批复意见（同意/不同意/部分同意+理由）→ 执行要求 → 落款。
要点：先明确表态再提要求；不同意必须给理由和替代建议。
篇幅：300–800 字。

**函** — 标题 → 主送单位 → 事由 → 商洽或告知事项 → 结语 → 落款。
要点：平等客气；请求事项留出回复时间。
篇幅：300–700 字。

**会议纪要** — 标题 → 会议时间/地点/主持人/参加人员 → 议题 → 会议内容（归纳各方意见）→
**议定事项（责任人+完成时限）** → 落款。
要点：核心是议定事项；发言归纳不逐字记录；有分歧要写清最终结论。
篇幅：800–2000 字。

**工作总结** — 标题 → 引言（总体情况与评价）→ 主要工作及成效（分若干方面，每方面带数据）→
存在问题与不足 → 下一步思路 → 结语。
要点：成效部分尽量用真实数据（数量、金额、比例、同比）；不足要真实可改；避免空话堆砌。
篇幅：1500–3500 字。

**工作计划** — 标题 → 指导思想与总体目标 → 重点工作任务（含目标值）→ 实施步骤与时间安排 →
保障措施（组织、经费、考核）→ 落款。
要点：任务可量化可考核；时间给节点；保障措施具体到责任部门。
篇幅：1200–2500 字。

**述职报告** — 标题 → 开头（任职情况与述职依据）→ 履职情况（思想政治、业务工作、重点工作）→
不足 → 努力方向 → 落款。
要点：第一人称；用具体事例和数据说明成绩。
篇幅：1500–3000 字。

**调研报告** — 标题 → 背景与方法（时间、对象、方式）→ 基本情况 → 问题及原因分析 →
对策建议 → 落款。
要点：问题分层（制度、机制、人员、保障）；建议与问题一一对应。
篇幅：2000–4000 字。

### 财务类

**财务报表说明** — 标题 → 编制依据与期间 → 总体收支情况 → 重点科目变动分析（增减额、幅度、原因）→
需说明事项（政策调整、一次性支出）→ 结语。
要点：所有数字取自用户报表；原因区分"政策性"与"业务性"。
篇幅：800–2000 字。

**预算说明** — 标题 → 编制原则与依据 → 收入预算说明 → 支出预算说明（功能分类、经济分类）→
与上年对比 → 重点项目说明 → 结语。
要点：支出逐科目写测算依据（人数×标准、合同金额）；增幅大的项目单列解释。
篇幅：1000–2500 字。

**审计说明／审计整改报告** — 标题 → 审计基本情况 → 发现问题及原因（逐条）→
整改措施与完成情况（逐条对应）→ 长效机制 → 结语。
要点：问题与整改**一一对应不漏项**；整改要有时间、凭证、责任人。
篇幅：1000–2500 字。

**经费申请** — 标题 → 申请单位/事项 → 申请理由（必要性+依据文件）→
经费预算明细（项目、金额、测算依据、合计）→ 资金来源与使用计划 → 结语与落款。
要点：必须给明细表和合计；测算依据要可核（标准、合同、往年实际支出）。
篇幅：500–1200 字。

**报销说明** — 标题 → 事由与时间 → 人员与行程/事项 → 费用明细（项目、金额、票据张数）→
合计（小写+大写）→ 特殊情况说明 → 落款与日期。
要点：金额写小写与大写；超标准部分单独说明并注明自理；票据张数与明细一致。
篇幅：300–800 字。

### 医疗类

**病历摘要** — 一般项目 → 主诉 → 现病史 → 既往史/个人史 → 体格检查（阳性体征）→
辅助检查（关键结果+时间）→ 入院诊断 → 诊疗经过 → 出院/当前情况 → 出院诊断与建议。
要点：只用用户提供的病历信息；缺失写「未提供」；数值与原始记录完全一致；规范医学术语。
篇幅：600–1500 字。

**病程记录** — 记录日期时间 → 当前症状与主诉变化 → 生命体征与重点查体 → 新检查结果 →
诊疗措施调整及理由 → 上级医师意见 → 小结与计划 → 签名。
要点：按时间顺序；只写有变化的内容；用药调整必须写理由；未做的检查不要写。
篇幅：300–800 字。

**出院小结** — 一般项目 → 入院/出院日期 → 入院诊断 → 入院情况 → 诊疗经过 →
出院诊断 → 出院情况 → 出院医嘱（药名、剂量、疗程、复诊时间、注意事项）→ 医师签名。
要点：医嘱必须具体；对患者用词通俗；诊断按主次排列。
篇幅：800–1500 字。

**病例报告** — 题目 → 摘要 → 关键词 → 引言 → 病例资料 → 讨论（诊断依据、鉴别诊断、
治疗选择、文献对照）→ 小结 → 参考文献。
要点：讨论是核心，说明本例特殊性；文献不虚构；结论不夸大。
篇幅：1500–3000 字。

**科室工作总结** — 标题 → 概述 → 医疗工作指标（门诊量、出院人次、手术量、平均住院日、
药占比等）→ 医疗质量与安全 → 教学科研 → 管理与团队 → 存在问题 → 下一年重点。
要点：指标要有同比/环比对比；只用用户提供的数据。
篇幅：1200–2500 字。

**科研论文初稿** — 题目 → 作者与单位（占位）→ 摘要（目的、方法、结果、结论）→ 关键词 →
前言 → 资料与方法 → 结果 → 讨论 → 结论 → 参考文献（占位）。
要点：方法与纳入排除标准必须写清；结果只写客观数据；**不自行计算 p 值或统计学结论**。
篇幅：3000–6000 字。

**教学材料** — 课题 → 授课对象与课时 → 教学目标（知识/技能/态度）→ 重点与难点 →
内容与时间分配 → 教学方法 → 思考题 → 参考资料。
要点：分层递进；突出临床实用性；列 2–3 个可提问的思考题。
篇幅：1000–2500 字。

### 通用类

**邮件** — 主题 → 称呼 → 开头问候与来意 → 正文（分点，每点先结论）→
需要对方做什么（动作+时间）→ 致谢 → 署名与联系方式。
要点：一件事一封邮件；把"需要对方做什么"放在显眼位置。
篇幅：200–600 字。

**演讲稿/发言稿** — 开场（点题）→ 主体（观点+论据+案例，2–3 组）→ 升华 → 结尾（号召或致谢）。
要点：口语化、短句；一个观点配一个具体例子；按每分钟约 200 字控制篇幅（用户给了时长就按时长算）。

**方案/策划书** — 名称 → 背景与目的 → 组织与分工 → 实施内容与流程（含时间表）→
资源与经费预算 → 风险与预案 → 效果评估方式。
要点：流程写到"谁在哪一步交付什么"；预算列明细；必须有风险预案。
篇幅：1500–3000 字。

**合同草案** — 名称 → 双方信息 → 标的与数量质量 → 价款与支付方式（含节点）→
履行期限地点方式 → 验收标准 → 违约责任 → 争议解决 → 其他约定 → 签署栏。
要点：开头或结尾明确标注「本合同为草案，正式签署前应经法务/律师审核」；金额、期限、
验收标准不得留空或含糊。
篇幅：1500–3500 字。

**规章制度** — 第一章 总则（目的、依据、适用范围）→ 第二章 职责分工 → 第三章 具体规定 →
第四章 监督检查 → 第五章 责任追究 → 第六章 附则（解释权、施行日期）。
要点：条款用"第X条"编号；用"应当""不得"而非"建议""最好"；写清违反后果。
篇幅：1500–3500 字。

### 数据类

**数据分析报告** — 标题 → 数据来源与口径说明 → 总体情况（关键总量）→
结构分析（构成、占比、排名）→ 趋势与对比（同比、环比）→ 异常与问题发现 → 结论与建议。
要点：写清口径（时间范围、单位、是否含税）；异常要指到具体行项；建议与发现一一对应。
篇幅：1000–2500 字。

## 四、从数据写材料的推荐流程

1. 先用表格工具读取数据，看清列名、行数与样例；
2. 做汇总统计，拿到总量、构成、排名、异常值（**不要心算，要用工具算**）；
3. 把统计结果作为素材写入正文；
4. 生成 Word 时用标题层级 + 表格；正文宋体、标题黑体、1.5 倍行距、首行缩进两字；
5. 结尾附：数据来源与口径、需要用户补充的信息清单。

## 五、交付前的自检清单

- [ ] 每个数字都能在源文件里找到出处
- [ ] 没有编造的人名、日期、文号、政策名、文献
- [ ] 层次序号规范（一、／（一）／1.）
- [ ] 日期、金额、单位写法统一
- [ ] 缺失信息都有明显的占位符，并在结尾汇总
- [ ] 需要审核的文件（合同、规章制度、论文）已注明需审核
- [ ] 最终文件已保存到用户工作区，并告知文件名与位置
